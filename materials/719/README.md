# 719 瓶与检验操作

inventory.json是明确初始业务日10的小输入，没有已有库存数据库。种类R的L=2，所有份数为整数，日期为整数日。operations.json按非递减日执行；reserve_competition让两个独立连接使用不同运行ID争同一LAST瓶，胜者不预定。

U总4份，入库10，预留时不设开封。12日reserve-U开始才开封并消耗1；新版方法M/v2随后消耗2，所以剩余未占1、预留0、消耗3。13日这1份可领；14日因开封12+2到期，当日可领0，但未占仍为1，守恒不能丢掉过期份数。

P总2份、开封9，10日预留1，11日开始过期失败：未占回到2、预留0、消耗0、当日可领0。LAST的一次成功预留仍不设开封，另一运行失败不占身份或数量。方法修订只作用于新运行；重复开始reserve-U不能再扣1。操作文件不要求强杀、分布式恢复或真实仪器。
