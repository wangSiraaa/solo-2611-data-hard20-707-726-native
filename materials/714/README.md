# 714 输入材料

这里提供新制作的小输入，没有旧目录实现或旧数据库。日期是整数日，JSON字段直接对应题面。

- catalog.json：销售A和三条特意乱序的替换；导入后链为A→B→C→D。
- operations.json：公开业务请求顺序，op用于说明动作，可映射到你实现的入口；confirm_competition表示两个独立连接同时确认，各自使用对应新序列号，不规定谁获胜。

手算：103日在用A；104至107日在用C；108日起为D。根保修[100,110)。late-C故障105、提交112资格合格，但不能再确认旧末端C。d-one/d-two竞争D最多一项新增替换；再次导入A→Z整批拒绝，已接纳链不变。故障110恰到期，且D当时仍有效，保修应拒绝。

材料中“操作”是所需业务调用，不是预设实现或调用分拆要求。请保存你实际执行文件后的目录/受理结果。
