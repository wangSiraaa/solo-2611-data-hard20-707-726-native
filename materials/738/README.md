# 成对评议与入围材料
全部为合成方案与评议，不涉及真实人物或决策规则。input.json给四个稳定方案、成对证据和名额；correction.json给同一证据的撤回新修订。operations.jsonl要求实际发布前后两个入围产品。

手算：初始严格多数边A→B、B→C、C→A、C→D。ABC构成一个强连通分量，凝聚后为{A,B,C}→{D}，源层为[A,B,C]然后[D]。名额2不能拆第一层，也不能跳到D，所以P1入围空、余2，记录被阻第一层ABC。

撤回E_CA的revision2覆盖其revision1，不回退旧有效票。新边A→B→C→D，源层依次[A]、[B]、[C]、[D]，P2按整层纳入A/B，余0。AN1和P1仍冻结循环时的证据、层与空入围结果。

反向票按同一无序对合计，平票无边；不把票数当路径权重，也不以微弱边为由擅断环。提供的核心算法由候选实现，材料不含排序器或入围后端。
