# 整数交叉表发布材料

`facts.json` 给出行列清单和已提交初始事实。数量为非负有理数，分母为正。`operations.jsonl` 依次提供初始发布、事实更正、新发布、读取旧产品和一次边际非法的对照。字段 `cut` 是对本操作文件中已提交切面的引用。工作库、产品和验证需实现。

初始精确表是 `[[3/2, 1/2], [1/2, 3/2]]`，行列合计均为 `[2, 2]`。`[[2,0],[0,2]]` 与 `[[1,1],[1,1]]` 都合法。`[[2,1],[1,2]]` 的每格仍在允许范围内，却破坏全部边际。

更正 `f-BX` 为 `3/2` 后，两行合计为 `[2,3]`，两列合计为 `[3,2]`。例如 `[[2,0],[1,2]]` 合法。再把该格更正为 `7/4` 可作为仓库事实保存，但发布不得成功，因为 B 行及 X 列边际为 `13/4`，旧两份发布保持不变。
