# 双偏移合成原件

JSON 中的 CRLF 转义解码后是真实回车与换行。逐字符 UTF-8 边界为 0,3,7,10,11,12,15,18,21，UTF-16 边界为 0,1,3,4,5,6,7,8,9。E1 的 Q2 与 P1 重叠而失败。E2 可见文本为“开🧭始”接 CRLF 接“甲█终”，Q3 的发布位置为 UTF-8 [18,21)、UTF-16 [8,9)。E3 可见文本为“开🧭始”接 CRLF 接“█终”，Q3 的发布位置改为 UTF-8 [15,18)、UTF-16 [7,8)。旧 E2 不因 E3 的规则更新改变。bad_anchor 的 start=2 不在合法标量边界。
